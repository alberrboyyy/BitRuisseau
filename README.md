## Introduction

Le projet "BitRuisseau" est une médiathèque audio partagée.
Le concept est simple : l'utilisateur gère et écoute ses morceaux locaux, puis peut consulter les médiathèques d'autres utilisateurs du réseau et importer leurs morceaux grâce à un protocole peer-to-peer.
Cette application est développée en Rust avec une interface en terminal basée sur ratatui, et utilise tokio pour la gestion asynchrone du réseau.

---

### Objectifs du Produit

L'objectif principal est de concevoir et réaliser un lecteur audio en deux étapes. D'abord une version standalone, qui permet de choisir les dossiers contenant ses morceaux, de les consulter avec leur titre, artiste, année, durée et taille de fichier, et de les écouter. Ensuite une version connectée, qui permet de voir les médiathèques disponibles sur le réseau, de consulter leur contenu et d'importer un morceau distant pour pouvoir l'écouter même quand la médiathèque distante est arrêtée.

---

### Objectifs Pédagogiques

Ce projet vise à mettre en pratique les concepts du module 321. Les objectifs incluent :
* Concevoir une application distribuée qui communique avec d'autres via un protocole P2P.
* Appliquer les principes de la programmation fonctionnelle.
* Réaliser un programme informatique de qualité.
* Utiliser un système de versioning de code comme Git de manière professionnelle.
